# Metaproc v0.2.0

## What’s Changed

### Features

- **Standalone workflow framework**: Install and run dependency-aware Markdown process
  specs with local handlers, agent CLI adapters, or optional GCP Batch execution.
- **Resumable execution**: Plan, run, resume, validate, inspect, and override workflows
  with structured state, traces, resource reports, usage records, and RunPool controls.
- **Extension surfaces**: Register contracts and handlers through plugins, install the
  packaged Agent Skill, and inspect artifacts with the packaged Metabrowser plugin.
- **Credential operations**: Manage labeled credential pools, probes, rotation, and
  adapter selection without embedding downstream workflow policy in Metaproc.

### Fixes

- **Portable frontmatter output**: Mapping-based YAML and frontmatter writes are
  deterministic and alias-free.
  Repeated values are expanded, and cyclic values fail without replacing an existing
  artifact.
- **Validation outcomes**: `metaproc softschema validate` reports SoftSchema’s `valid`,
  `invalid`, or `input_error` outcome alongside the existing `ok` field.

### Compatibility

- `metaproc softschema compile` requires `--contract CONTRACT_ID`.
- Contract IDs must use `[namespace:]Name[/version]`. The structure-report contract is
  `metaproc:StructureReport/v1`; regenerate reports created with the former ID.
- YAML validation accepts bounded JSON-compatible values and rejects aliases, anchors,
  merge keys, explicit tags, duplicate or non-string keys, unsafe numeric values, deep
  or oversized inputs, and implicit remote schema references.
  Date- and timestamp-shaped YAML scalars remain strings.

### Guidelines and Content

- **Portable Agent Skill**: `metaproc skill metaproc --install` installs the packaged
  Metaproc workflow guidance for supported coding agents.
- **Packaged operator guidance**: The installed distribution includes command,
  environment, format, and workflow documentation used by the CLI and Agent Skill.
