# Metaproc v0.7.0

This release refreshes the model catalog and pricing across all four agent adapters.
It adds the Gemini 4 family, retains exact access to Gemini 3.6 Flash for eligible
accounts, and keeps completed work reusable when an adapter default moves.

## What’s Changed

### Features

- **Gemini.** Gemini 4 Hydrogen, Neon, Argon, and Carbon have named profiles.
  The `gemini-flash-36` profile still requests `gemini-3.6-flash` exactly.
  Gemini 3.8 Flash is available as an experimental profile.
  For Gemini 3.7 Flash, 3.5 Flash, 3.1 Flash-Lite, and 3 Flash Preview, use Pi with the
  explicit `google-vertex` provider.
  For 3.5 Flash, `pi-gemini-flash` selects that route for you.
- **Claude and OpenAI.** The catalog accepts Claude Fable 5.2 and Claude Opus, Sonnet,
  and Haiku 5.5. It also accepts GPT-6.2 Astra and Sol, GPT-6.1 Sol and Terra, and GPT-6
  Sol and Luna. Codex defaults to GPT-6.1 Sol.
  The Claude Code `opus` and Pi `sonnet` defaults keep their names and resolve to
  versions 5.5 on the new CLI pins.
  Exact provider routes and live coverage vary by model and authentication method.
- **Other provider models and costs.** The refresh includes GLM-5.2 and DeepSeek V4.1
  Flash on Vertex MaaS, DeepSeek Flash on the direct provider, and Kimi K3 and K3.1 Pro
  through Pi, including K3.1 Pro Highspeed on the direct Moonshot route.
  Updated pricing includes input, output, and cache rates where published.
  Historical rows remain available for earlier runs.

For exact model IDs, auth routes, and probe results, see the
[model and harness review](https://github.com/jlevy/metaproc/blob/v0.7.0/docs/project/research/research-2026-11-18-model-and-harness-refresh.md)
and the [changelog](https://github.com/jlevy/metaproc/blob/v0.7.0/CHANGELOG.md).

### Fixes

- **Resume across model changes.** A retained run keeps the artifact namespace it
  started with. Metaproc records a changed default and reuses completed steps.
  Retained runs on removed built-in profiles can still be inspected, and Metaproc names
  the successor and override when new work needs a model the old route can no longer
  serve.
- **Check model selection accurately.** `auth-check --assert-model` checks Gemini’s
  billed model, including documented aliases.
  With Codex 0.166.0 it verifies the requested model in the rollout.
  Codex does not report the served model on that interface.
- **Use existing Codex credentials.** Metaproc bridges `OPENAI_API_KEY` for eligible
  API-key runs and accepts the current ChatGPT credential file shape.
  A stored ChatGPT login keeps precedence and subscription billing.
- **Keep adapter settings consistent.** Gemini runs apply a high thinking level and use
  static model resolution to preserve explicit choices.
  Relaunches on older Metaproc-managed workspace defaults update those defaults and
  preserve operator settings.
  Pi disables built-in MCP and telemetry for Metaproc launches.

## Upgrade Notes

- The adapter pins are Claude Code 2.1.325, Codex 0.166.0, Gemini CLI 0.66.0, and Pi
  1.5.2. Rebuild images that install the CLIs.
  Wheel-enabled GCP workers need Python 3.14 or newer.
  Check the interpreter and harnesses in the deployed image before updating it.
  The interpreter check was verified on a downstream worker image with Python 3.14.9 in
  `/opt/venv`.
- Google Vertex blocked new and inactive projects from using Gemini 3.6 Flash on
  November 19, 2026. Eligible active projects retain access until January 28, 2027.
  Gemini 3.7 Flash also retires on Vertex on January 28. Use Gemini 4 Hydrogen for
  migrations and keep separate run IDs when comparing results.
  [Vertex model lifecycle](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/model-versions)
- The removed `gemini-flash` profile used a Gemini CLI route that rewrites Gemini 3.5
  Flash to 3.8. Use `pi-gemini-flash` for exact Gemini 3.5 Flash or `gemini-hydrogen`
  for the recommended current Flash-class profile.
  For the retired `pi-glm5` profile, use `pi-glm52`.
- The browser extra continues to pair Metabrowser 0.9.1 with plugin SDK 0.5. Gemini file
  tools can still read ignored files in the workspace with the shipped settings.
  Keep secrets outside the agent’s working directory.
