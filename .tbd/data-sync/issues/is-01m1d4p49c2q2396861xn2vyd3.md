The scalar-agent nonzero-exit rescue currently runs for any exit_error, including RunPool kill reasons, although the policy and evidence justify overriding only an unreliable process exit code. Its precheck also validates output templates with the parent variables instead of the step variables that bind the effective execution profile and artifact namespace, and the accepted anomaly survives only as suppressible progress output rather than durable attempt evidence. Restrict the override to nonzero exits without a supervisor kill, validate with the same resolved step variables and repair/conform ordering as normal completion, retain durable anomaly evidence, and add integration tests for rescued exit, pool kill, variant output, invalid output, and outputless cases.
