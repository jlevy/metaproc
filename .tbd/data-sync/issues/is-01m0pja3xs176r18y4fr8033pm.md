`docs/agent-toolchain-bootstrap.md` was written before the pattern existed upstream. It
has since been generalized into a tbd guideline, `agent-session-bootstrap`, merged in
jlevy/tbd PR #248 (`c4dd9f38`). Once that ships in a released `get-tbd` and this repo
adopts that release, most of the metaproc doc becomes a duplicate of the guideline.

Trim it to the parts that are actually Metaproc-specific — which pins this repo uses,
where the script lives, how `check_supply_chain.py` guards it — and point at
`tbd guidelines agent-session-bootstrap` for the general pattern, the fit test, the
alternatives, and the PATH and pin-drift traps.

BLOCKED until: `agent-session-bootstrap` appears in a released `get-tbd` version and
that version is adopted here under the supply-chain policy (first-party exemption
applies, but the version change still needs a review and an updated rationale in
SUPPLY-CHAIN-SECURITY.md). Verify with `tbd guidelines --list` after upgrading. Do not
trim before then: the doc would point at a guideline this repo cannot load.

Also update the README documentation-map row and the SUPPLY-CHAIN-SECURITY.md link that
reference the doc, and re-run `make verify` (local Markdown link checking is part of it).
