src/metaproc/models/authored.py:648-653 derives identity names from the current spec only and src/metaproc/commands/run_process.py:1609-1613 compares them against ordinary saved variables; the creation record stores no identity declaration or binding. Two opposite failures: removing an identity input permits resume and records its disappearance (and remove-flag, change-value, restore-flag succeeds, so the original value is no longer enforced); renaming param: AS_OF to AS_OF_DATE with the same logical input and date refuses with 'AS_OF_DATE: <unset> -> ...'. Fix: persist identity bindings at run creation under stable logical input keys with the policy that established them; resolve aliases before comparing and compare each logical value once; define recorded transitions for removing or adding a binding on an existing run; runs without a binding acquire no fictional historical guarantee.
