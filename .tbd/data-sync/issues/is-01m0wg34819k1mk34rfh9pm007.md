A successful agent run that recovers from an ignored tool error can still project its session and attempt as failed. Replayed logs can also place an earlier event after a later compaction timestamp, producing invalid bounds. Preserve the failed tool span with recovered evidence, suppress only its upward severity after a successful terminal result, and derive valid attempt bounds from the terminal result and duration.
