`.claude/scripts/` and `.codex/` carry three byte-identical pairs of hook scripts
(`ensure-gh-cli.sh`, `tbd-session.sh`, `tbd-closing-reminder.sh`) with nothing testing
that the copies stay in step. They are generated by `tbd setup --auto`, so they are
regenerated together today, but a hand edit to one copy would drift silently.

PR #19 deliberately did NOT add a fourth pair: `devtools/ensure-toolchain.sh` is a single
agent-neutral script that both agent configs invoke by path, and `check_supply_chain.py`
asserts both configs still reference it. De-duplicating the three pre-existing pairs the
same way is the matching cleanup.

Two options, pick one:
1. Point both agent configs at one shared path (mirrors what the toolchain bootstrap
   does) — but these three are tbd-generated, so `tbd setup --auto` would rewrite them
   back. That makes this an upstream change to tbd's generator, not a local one.
2. Keep the copies and add a drift check to `check_supply_chain.py` asserting the pairs
   are byte-identical — local, cheap, and catches the hand-edit case without fighting
   the generator.

Option 2 is the smaller change and does not depend on upstream. Option 1 is the real fix
but belongs in jlevy/tbd.
